# 작동 원리

`index.html` 안의 코드가 하는 일을 순서대로 설명합니다. 함수 이름을 함께 적었으니 코드와 대조해 볼 수 있습니다.

## 1. 계보 구축 — `buildAncestry`

시작 논문에서 출발해 **참고문헌 방향(조상 방향)** 으로 단계별 너비 우선 탐색을 합니다.

1. 현재 단계의 논문들의 `referenced_works`(참고문헌 목록)를 읽습니다. 비어 있고 "Semantic Scholar 보완"이 켜져 있으면 Semantic Scholar에서 DOI로 참고문헌을 받아 OpenAlex ID로 바꿉니다.
2. 아직 모르는 참고문헌의 정보를 OpenAlex에서 100편씩 묶어 가져옵니다(`fetchWorks`).
3. **논문당 전체 인용수가 높은 상위 N편(`topRefs`)만** 다음 단계로 확장합니다. 인용망이 기하급수로 커지는 것을 막기 위한 가지치기입니다. "분야 제한"을 넣으면 그 문자열이 분야·하위분야·주제명에 들어 있는 논문만 확장합니다.
4. 수집한 논문 수가 상한(`maxPapers`)에 닿거나 단계 수에 도달하면 멈춥니다.

모든 참고 관계는, 수집된 논문끼리라면 확장하지 않은 논문까지 간선으로 기록합니다. 그래야 "서로 다른 갈래가 같은 조상으로 수렴하는 정도"를 정확히 셀 수 있습니다.

## 2. 그래프 정리와 시조 점수 — `analyze`

- **순환 제거**: 논문을 (출판연도, ID) 순으로 정렬해 순서를 매기고, 인용된 논문이 더 앞선 순서인 간선만 남깁니다. 같은 해 상호 인용이나 데이터 오류로 생기는 순환이 자연스럽게 사라지고, 그래프가 비순환(DAG)이 됩니다. 출판연도 정보가 없는 논문은 제외됩니다.
- **조상 집합**: 시작 논문에서 간선을 따라 도달할 수 있는 모든 논문입니다.
- **경로 수**: 시작 논문에서 각 조상까지 가는 서로 다른 인용 경로의 수를 DAG 위에서 동적 계획법으로 셉니다. 여러 갈래가 수렴하는 논문일수록 큽니다.

각 조상 논문에 대해 다섯 지표를 계산하고, 지표마다 **순위 백분위(0~1, 동률은 평균 순위)** 로 바꾼 뒤 가중합합니다.

| 지표 | 가중치 | 뜻 |
|---|---|---|
| 경로 수 (로그) | 30% | 여러 갈래가 수렴하는 정도 |
| 조상 내 피인용 | 25% | 수집된 조상 논문들 중 이 논문을 인용한 수 |
| 전체 인용수 (로그) | 15% | 학계 전체에서의 영향력 |
| 오래됨 | 20% | 조상 중 얼마나 앞선 연도인가 |
| 의미 키워드 유사도 | 10% | 시작 논문과 단어 벡터의 코사인 유사도 |

가중치는 `WEIGHTS` 상수에서 바꿀 수 있습니다. **주 계보**는 시작 논문에서 점수 1위 후보까지 가는 경로 중 경로상 논문의 로그 인용수 합이 최대인 사슬입니다.

## 3. 의미 키워드와 주제 묶기 — `buildSemantic`, `groupSemantic`

**단어 추출** (`extractTerms`) — 논문 하나에서 다음을 뽑습니다.

| 출처 | 가중치 |
|---|---|
| OpenAlex 키워드(구 단위) | 0.6 + 0.4 × 키워드 점수 |
| 제목의 인접 두 단어 구 | 0.8 |
| 제목의 단어 | 0.5 |
| OpenAlex 주제명 속 단어 (보조 신호) | 0.4 |

불용어(`STOP`)와 범용어(`GENERIC`: analysis, study, effect …)는 제외합니다. 어근이 같은 단어는 가벼운 규칙으로 합칩니다(wars→war, economics→economic, parties→party).

**벡터화** — 수집한 논문 전체를 문서 집합으로 보고 TF-IDF(`가중치 × ln(1 + N/df)`)를 계산합니다. 한 편에만 나오는 단어(df < 2)와, 수집 논문의 절반(최소 3편)을 넘는 논문에 나오는 단어는 변별력이 없어 제외합니다. 논문 벡터는 길이 1로 정규화합니다.

**묶기** (`clusterPapers`) — 코사인 유사도 기반 구면 k-means입니다.
- 초기 중심: 가장 많이 인용된 논문에서 시작해, 기존 중심들과 멀면서(`1 − 최대 유사도`) 인용이 많은 논문을 차례로 고릅니다. 무작위가 없어 같은 입력이면 항상 같은 결과가 나옵니다.
- 최대 15회 반복하며 논문을 가장 가까운 중심에 배정하고 중심을 갱신합니다.
- 1편짜리 묶음은 해체해 가장 가까운 묶음으로 보내고, 어디에도 가깝지 않으면 "기타(키워드 부족)"로 보냅니다.
- 묶음 이름은 중심 벡터에서 가중치가 높은 단어 3개입니다. 구는 가중치를 25%씩 더 쳐 주고, 서로 포함 관계인 단어(civil / civil war)는 하나만 남깁니다.
- 지도에서는 시작 논문과 중심 벡터가 가까운 주제부터 위에서 아래로 배치합니다.

**핵심 키워드의 기원** (`termOrigins`) — 시작 논문의 벡터에서 가중치가 높은 단어 순서로, 조상 논문 중 **제목이나 OpenAlex 키워드에 직접 나온** 가장 이른 논문을 찾습니다. OpenAlex 주제명은 나중에 알고리즘이 소급해서 붙이므로 "그 단어를 썼다"는 증거로 쓰지 않습니다.
